flopscope.stats.lognorm.ppf

flopscope.stats.lognorm.ppf(q, s, loc=0, scale=1)[flopscope source]

Evaluate the percent-point function.

Parameters

q:array_like

Probabilities in [0, 1].

s:float

Shape parameter of the distribution.

loc:float, optional

Location parameter. Defaults to 0.

scale:float, optional

Scale parameter. Defaults to 1.

Returns

:FlopscopeArray

Quantiles corresponding to q.

Notes

Equivalent to scipy.stats.lognorm.ppf(q, s, loc, scale). FLOP cost: 106 * numel(broadcast(q, s, loc, scale)) (composite: ndtri + exp, weight 1.0).
